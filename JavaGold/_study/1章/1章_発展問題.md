## 総合問題(複数セクション横断)

### 総合問題1

(2.ジェネリクス × 5.ソート × 6.便利メソッド)

```java
 1  import java.util.ArrayList;
 2  import java.util.Collections;
 3  import java.util.Comparator;
 4  import java.util.List;
 5
 6  class Player<T extends Number> implements Comparable<Player<T>> {
 7      String name; T score;
 8      Player(String name, T score) { this.name = name; this.score = score; }
 9      public int compareTo(Player<T> o) { return Double.compare(score.doubleValue(), o.score.doubleValue()); }
10     public String toString() { return name; }
11 }
12 public class Main {
13     static <T extends Number> Player<T> topScorer(List<Player<T>> players) {
14         return Collections.max(players);
15     }
16     public static void main(String[] args) {
17         List<Player<Integer>> players = new ArrayList<>();
18         players.add(new Player<>("A", 10));
19         players.add(new Player<>("B", 30));
20         players.add(new Player<>("C", 20));
21         System.out.println(topScorer(players));
22         System.out.println(Collections.max(players, Comparator.comparing(p -> p.name)));
23     }
24 }
```

このコードを実行するとどうなるか、最も適切なものを1つ選べ。

A. `B` の後 `C`

B. `B` の後 `A`

C. コンパイルエラーになる(14行目)

D. `C` の後 `B`
