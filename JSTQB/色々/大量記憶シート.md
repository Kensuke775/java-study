# JSTQB 大量記憶シート

紙のシートを書き写したもの。列の数字は、前回からあける間隔（日数）。解いた日付を左から順に埋めていく。

**ルール**

- 0：最初に解いた日。0.5：同じ日にもう1回
- そのあとは、列の数字の日数だけあけて次を解く（1日後 → 1日後 → 1日後 → 2日後 → 2日後 → 3日後 …）
- 間違いが多くても気にしない。そのまま次の列へ進む
- 試験（11/1 か 11/8）までに届かない列（5, 5, 6, 6, 7, 7）は消した。表の最後まで終わったら、試験まで4日ごとに繰り返す
