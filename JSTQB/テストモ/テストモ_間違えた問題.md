# テストモ 間違えた・迷った問題（2026-11-03）

テストモで解いて、間違えた・迷った問題。正解は一番下。

## 問題

**問1**　インスペクションの目的として、最も不適切なものはどれか。

- A：作成者のモチベーションの向上と改善
- B：ウォークスループロセスの改善
- C：不正を最大数発見すること
- D：品質評価や作業成果物に対する信頼の積み上げ

**問2**　静的テストが早期に検出できる欠陥の例として、最も適切なものはどれか。

- A：特定の種類のセキュリティ脆弱性
- B：ユーザーのフィードバックに対する応答性
- C：システムの性能効率性の低下
- D：ユーザーの操作性

**問3**　デバッグの流れに関して、最も適切なものはどれか。

- A：デバッグの流れは、まず故障の再現を行い、次に欠陥を修正し、最後に診断を行う
- B：デバッグの流れは、まず原因を修正し、次に欠陥の再現を行い、最後に診断を行う
- C：デバッグの流れは、まず故障の再現を行い、次に診断を行い、最後に原因を修正する
- D：デバッグの流れは、まず診断を行い、次に欠陥の再現を行い、最後に原因を修正する

**問4**　テストコントロールの指示として、最も適切なものはどれか。

- A：影響を受ける品質特性に対応した適切なテストタイプを適用する
- B：リスクタイプに適した経験やスキルのレベルを持つテスト担当者を選ぶ
- C：適切なレベルのテストの独立性を適用する
- D：識別したリスクが問題になった場合のテストの優先度の見直し

**問5**　テスト自動化の潜在的なリスクとして、最も適切なものはどれか。

- A：テスト自動化により、人間が導き出すには複雑すぎる尺度の提供をすることがある
- B：自動化ツールが開発プラットフォームと互換性がある
- C：テストツールの利点に非現実的な期待を持つことがある
- D：テストツールの導入により、新たな業務手順を学ぶ時間を節約することがある

**問6**　代表的なテストメトリクスの内容として、適切なものはどれか。

- A：プロダクトの可用性
- B：プロジェクトの予算状況
- C：テストケースの設計進捗
- D：テストスキルの向上度

**問7**　テスト進捗レポートは通常、どのような頻度で作成されるか。

- A：事前に合意された頻度
- B：隔週
- C：毎日
- D：毎週

**問8**　テストメトリクスは、何を示すために収集されるか。

- A：テストの計画状況
- B：テストの開始状況
- C：テストの進捗状況
- D：テストの完了状況

---

## 正解とポイント

| No | 正解 | ポイント |
| --- | --- | --- |
| 1 | B | 「不適切」を聞いている。C は主な目的（3.2.4） |
| 2 | A | 3.1.3 のリスト（バッファオーバーフローなど） |
| 3 | C | 再現 → 診断 → 修正。原因が分からないと直せない（1.1.2） |
| 4 | D | A〜C は 5.2.4 のリスク軽減。D だけが 5.3 のコントロールの指示 |
| 5 | C | B は「互換性が**ある**」、D は「学ぶ時間を節約」で、どちらもシラバスの逆（6.2） |
| 6 | A | 5.3.1 にそのままの言葉で載っている。B・C は言い回しがずれている |
| 7 | A | シラバスは「定期的に（毎日、毎週など）」。毎日・毎週は例にすぎない（5.3.2） |
| 8 | C | 「計画したスケジュールや予算に対する進捗状況」（5.3.1） |

※問7・問8の正解は、テストモの解説ではなくシラバスをもとに判断したもの（未確認）。
