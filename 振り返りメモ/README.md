# 振り返りメモ

毎朝1本、前日にJavaで学んだ内容から1トピックだけを選んで書く短い記事を置く場所。GitHubのコントリビューショングラフを継続させる目的の毎日更新用フォルダ。

## 構成

月ごとにサブフォルダを分ける。

```
振り返りメモ/
  2026-09/
    2026-09-08.md
    2026-09-09.md
  2026-10/
    2026-10-01.md
```

## 運用フロー

1. 毎朝7:30に`scripts/daily_review_notify.sh`(launchd経由)がmacOS通知を出し、ターミナルでこのリポジトリを開く
2. その日のうちに、前日の`reflect/`配下の振り返りメモから1トピックを選び、`振り返りメモ/YYYY-MM/YYYY-MM-DD.md`として記事を書く(Claude Codeとの対話で作成)
3. 作成後は`git add`・`git commit`・`git push`まで行う(内容確認は必ず人間が行ってからpushする)
