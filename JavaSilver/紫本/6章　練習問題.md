**間違えた問題**：

**✴︎を付けた問題の振り返り**：6-1, 6-3, 6-4, 6-15, 6-16, 6-19, 6-20, 6-22, 6-23に付けた。うち6-16と6-19が不正解で、それ以外は正解。

- **6-8（toString）**：その理解でOKです。`Object.toString()`の標準は`クラス名@ハッシュ値`（`Plain@251a69d7`）で、オーバーライドすると`println(obj)`の表示が変わります。配列は`toString`をオーバーライドしていないので`[I@764c12b6`になり、そのために`Arrays.toString(arr)`があります。自作クラスは自分で`toString()`を書きます。なお`record`は自動生成で、`Item[no=1, name=A]`と出ます。
- **6-16（permits）**：はい、エラーになります。`permits`に書いていないクラスが`extends`すると、「クラスはシール・クラスSを拡張できません('permits'句に指定されていないためです)」と出ます。`permits`を省略して同じファイル内で継承する場合は、エラーになりません。
- `permits`と`extends`は、次のように両方が揃って初めて成立します。

  | 状態                           | 結果                                      |
  | ---------------------------- | --------------------------------------- |
  | `permits A`＋`A extends S`    | OK                                      |
  | `permits A`＋Aが`extends`していない | 「無効なpermits句」コンパイルエラー                   |
  | `permits`にBが無い＋`B extends S` | 「'permits'句に指定されていないためです」（前回確認）コンパイルエラー |

- **6-19（ArrayListとtoString）**：`ArrayList`は`AbstractCollection`の`toString()`を持っているので、自分で書かなくても`println(list)`で`[1, 2]`と出ます。
- **6-22（mapの出力）**：`HashMap`も`AbstractMap`の`toString()`を持っていて、`{DE=Germany, UK=United Kingdom}`と出ます。ただし6-22は`map.add`が存在しないメソッドなので、そこでコンパイルエラーになります。正しくは`put`です。
- **6-20（set）**：戻り値は置き換える前の要素で、新しく入れた値ではありません。元が`null`なら`null`が返ります。できなかった場合（添字が範囲外）は、6-19と同じ`IndexOutOfBoundsException`です。
- **6-23（C）**：ジェネリクスは共変ではなく不変です。`List<Object> list = new ArrayList<String>();`は、「ArrayListをListに変換できません」というエラーになります。共変なのは配列のほうで、`Object[] a = new String[1];`は通ります。ただし`a[0] = 1;`は実行時に`ArrayStoreException`になります。
- **6-24（mismatch）**：はい、`equals()`で比較しています。`new String("200")`は`==`だと`false`ですが、`equals`だと`true`なので一致扱いです。`oArr[2]`（`Integer` 300）と`sArr[2]`（`"300"`）は`equals`が`false`なので、添字2が返ります。全部一致すれば`-1`です。
