# `{}`は「要素数0の配列」であって「中身が空の1個の箱」ではない

## 検証コード

```java
public class Main {
    public static void main(String[] args) {
        try {
            int[] array = {};
            array[0] = 10;
            System.out.println("finish");
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("error");
        }
    }
}
```
→ `error`と表示される。検証済み。

## なぜ`array[0]`が存在しないのか

`int[] array = {};`は、**要素数0の配列**を作るという意味。`array.length`は`0`になる。

配列の有効なインデックスは`0`から`length - 1`まで。`length`が`0`なら、有効なインデックスの範囲自体が存在しない（空っぽ）。「配列を作った」＝「インデックス0の箱が用意された」ではなく、「配列を作った」＝「指定した個数分だけ箱が用意された」で、今回は個数として`0`を指定したことになる。

## イメージの修正

- ❌ 誤解：`{}`は「中身が空（未初期化）だけど、箱自体は1個ある」
- ✅ 正しい：`{}`は「箱の個数そのものが0個」

## 比較

```java
int[] array1 = {};         // 長さ0（要素なし。array1[0]は存在しない）
int[] array2 = new int[1]; // 長さ1（array2[0]は存在し、デフォルト値0が入っている）
int[] array3 = {0};        // 長さ1（array3[0]は存在し、値は0）
```

`array1`は「要素数ゼロの配列」であり、`array2`・`array3`のように「1個の箱があって、その中身が`0`」というのとは全く別物。`array[0] = 10;`は、そもそも存在しない1番目の箱に書き込もうとしているので、`ArrayIndexOutOfBoundsException`になる。

## まとめ

- `{}`（中身なしの配列初期化子）は**要素数0の配列**を作る
- 要素数0ということは、`array[0]`を含めて一切のインデックスアクセスが範囲外
- 「箱はあるが中身が空」ではなく「箱の数そのものがゼロ」という理解が正しい
