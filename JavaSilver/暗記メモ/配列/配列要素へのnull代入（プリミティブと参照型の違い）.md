# 配列の要素にnullを代入できるか（プリミティブ型と参照型の違い）

## 参照型の配列（String[]など）：null代入OK

```java
String[] array = {"A", "B", "C", "D"};
array[0] = null;
for (String str : array) {
    System.out.print(str);
}
```
→ コンパイル・実行成功。出力は`nullBCD`。

`String`は参照型なので、配列の要素に`null`を入れるのは合法。`print`/`println`は`null`を渡されても例外にならず、`"null"`という文字列に変換して表示する。

## プリミティブ型の配列（int[]など）：null代入はコンパイルエラー

```java
int[] array = {1, 2, 3, 4};
array[0] = null;
```
```
エラー: 不適合な型: <null>をintに変換できません
```
→ 検証済み。

## なぜ違うのか

`int`はプリミティブ型であり、そもそも「参照が何も指していない」ことを表す`null`という概念が存在しない。`String[]`（参照型の配列）の各要素は「オブジェクトへの参照」なので`null`を持てるが、`int[]`（プリミティブ型の配列）の各要素は`int`そのもの（値そのもの）なので、`null`を代入しようとした時点でコンパイルエラーになる。

## まとめ

| 配列の要素の型 | `null`を代入できるか |
|---|---|
| 参照型（`String`など） | ✅ できる |
| プリミティブ型（`int`など） | ❌ できない（コンパイルエラー） |
