# 整数リテラルの種類（2進数・8進数・10進数・16進数）

Javaの整数リテラルは、先頭の記号によって「何進数として解釈するか」が変わる。

| 種類 | 先頭 | 使える数字/文字 | 例 | 10進数での値 |
|---|---|---|---|---|
| 2進数 | `0b`または`0B` | 0, 1 | `0b1010` | 10 |
| 8進数 | `0`（数字の0のみ） | 0〜7 | `010` | 8 |
| 10進数 | なし | 0〜9 | `10` | 10 |
| 16進数 | `0x`または`0X` | 0〜9, A〜F（a〜fも可） | `0x10` | 16 |

```java
int a = 0100;      // 8進数 → 64
int b = 0777;      // 8進数 → 511
int c = 020;       // 8進数 → 16
int d = 0xF;        // 16進数 → 15
int e = 0x10;       // 16進数 → 16
```
→ 検証済み。

---

## 8進数（`0`で始まる）

- 使える数字は**0〜7の8種類のみ**
- `0`の後に続く数字がある場合、その数値全体が8進数として解釈される（`010`は「10」ではなく「8進数の10」＝10進数で8）
- 桁の重みは10進数と同じ考え方で、右から$8^0, 8^1, 8^2...$の位取り
- **7の次（＝8になるところ）で繰り上がる**（10進数が9の次に繰り上がるのと同じ仕組み）

```
7 -> 7
8 -> 10   ← ここで繰り上がる
9 -> 11
15 -> 17
16 -> 20  ← ここでも繰り上がる
```
（`Integer.toOctalString(i)`で検証済み）

**存在しない数字（8, 9）を使うとコンパイルエラー**：

```java
int e = 018;
```
```
エラー: ';'がありません
```
→ 検証済み。`018`は不正な数値リテラルとしてパースの時点でエラーになる。

---

## 16進数（`0x`で始まる）

- 使える文字は**0〜9とA〜F（大文字・小文字どちらも可）の16種類**（だから「16進数」）
- 10→A, 11→B, 12→C, 13→D, 14→E, **15→F**（**Fまでで、Eまでではない**。「16進数はEまで」は誤り）
- Fを使い切って初めて繰り上がる

```
14 -> e
15 -> f   ← ここまで使う
16 -> 10  ← Fの次で繰り上がる
```
（`Integer.toHexString(i)`で検証済み）

---

## まとめ

| 観点 | 8進数 | 16進数 |
|---|---|---|
| プレフィックス | `0`（数字の0） | `0x` / `0X` |
| 使える記号 | 0〜7 | 0〜9, A〜F |
| 繰り上がりの位置 | 7の次 | Fの次 |
| 誤りやすい点 | `010`を「10」だと思ってしまう | 「Eまで」だと思ってしまう（正しくはFまで） |
