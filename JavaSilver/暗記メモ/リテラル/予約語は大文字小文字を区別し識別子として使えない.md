# 予約語（null・void・trueなど）は大文字小文字を区別し、識別子としてどこでも使えない

## 検証1：`NULL`（大文字）は`null`として機能しない

```java
String s = NULL;
```
```
エラー: シンボルを見つけられません
        String s = NULL;
                   ^
  シンボル:   変数 NULL
```
→ 検証済み。`NULL`は予約語の`null`とは別物で、「`NULL`という名前の変数を探したが見つからない」というエラーになる。

## 検証2：`NULL`は逆に、普通の変数名としてなら使える

```java
String NULL = "これは普通の変数名です";
System.out.println(NULL);
```
```
これは普通の変数名です
```
→ 検証済み。予約語ではないので、識別子として何の制約もなく使える。

## 検証3：`void`（小文字・予約語）は引数名に使えない

```java
public static void sample(int void) {
}
```
```
エラー: <identifier>がありません
    public static void sample(int void) {
                                 ^
```
→ 検証済み。

## 検証4：`Void`（大文字始まり）なら引数名として使える

```java
public static void sample(int Void) {
    System.out.println(Void);
}
```
```
5
```
→ 検証済み。`java.lang.Void`という実在のクラス名と綴りが一致するが、それとは無関係にただの識別子として使える。

## 検証5：引数に限らず、識別子が使われる場所ならどこでも同じルールが適用される

```java
public void class() {}        // メソッド名 → エラー
public class int {}           // クラス名 → エラー
int true = 5;                 // ローカル変数名 → エラー
```
→ すべて検証済み。いずれも「識別子が見当たりません」系のコンパイルエラー。

## 解説

Javaの`null`・`true`・`false`・`void`・`class`・`int`・`static`などは、言語仕様上あらかじめ特別な意味が割り当てられている**予約語**。予約語は**大文字小文字を区別**し、正確な綴り（すべて小文字）でなければ予約語として認識されない。

「識別子（identifier）」とは、変数名・引数名・メソッド名・クラス名・フィールド名など、プログラマが好きな名前を付けられる場所すべてを指す共通の概念。予約語は、この「識別子」というカテゴリに属することが言語仕様上**一律で禁止**されている。つまり「引数だから特別」「メソッド名だから特別」ということはなく、**「識別子が必要な場所」という1つの大きなグループ全体に対して、予約語だけがまとめて締め出されている**。

大文字を混ぜる（`NULL`・`Void`・`True`など）と予約語の判定から外れ、ただの識別子として自由に使えるようになる。

## まとめ

| | 小文字（正確な予約語の綴り） | 大文字を含む綴り |
|---|---|---|
| 識別子として使えるか | ❌ どこでも使えない（変数名・引数名・メソッド名・クラス名など） | ✅ 普通の識別子として使える |
