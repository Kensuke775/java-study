# 初期化の実行順序：static初期化子（1回だけ）→ インスタンス初期化子・コンストラクタ（毎回）

## 検証コード

```java
public class Sample {
    static {
        System.out.println("static初期化子");
    }
    {
        System.out.println("インスタンス初期化子");
    }
    public Sample() {
        System.out.println("コンストラクタ");
    }
}

public class Main {
    public static void main(String[] args) {
        System.out.println("--- 1個目 ---");
        new Sample();
        System.out.println("--- 2個目 ---");
        new Sample();
    }
}
```
```
--- 1個目 ---
static初期化子
インスタンス初期化子
コンストラクタ
--- 2個目 ---
インスタンス初期化子
コンストラクタ
```
→ 検証済み。

## 整理

- **static初期化子**：そのクラスが最初に使われる（≒最初にロードされる）タイミングで**1回だけ**実行される。何個インスタンスを作っても、2回目以降は実行されない
- **インスタンス初期化子**：`new`するたび、**毎回**実行される
- **コンストラクタ**：`new`するたび、**毎回**実行される

1回の`new`ごとの実行順序は「**インスタンス初期化子 → コンストラクタ**」。static初期化子は、一番最初の`new`より前に、クラス全体に対して1回だけ先に割り込む。

## まとめ

| | 実行タイミング | 実行回数 |
|---|---|---|
| static初期化子 | クラスが最初に使われる時 | 1回だけ（何個インスタンスを作っても） |
| インスタンス初期化子 | `new`するたび | 毎回 |
| コンストラクタ | `new`するたび（インスタンス初期化子の後） | 毎回 |

全体の順序：`static初期化子（最初の1回だけ）` → `1個目: インスタンス初期化子 → コンストラクタ` → `2個目: インスタンス初期化子 → コンストラクタ` → ...
