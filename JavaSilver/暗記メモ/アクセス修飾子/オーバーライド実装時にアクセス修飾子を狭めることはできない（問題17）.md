# オーバーライド・インターフェース実装時にアクセス修飾子を狭めることはできない（問題17）

## 前提：interfaceの抽象メソッド・defaultメソッドは両方とも暗黙的にpublic

```java
interface A {
    default void sample() { System.out.println("A"); }
}
interface Worker {
    void work();
}
```

`sample()`も`work()`も、修飾子を書かなくても**暗黙的に`public`**。

## ケース1：defaultメソッドをprivateで実装 → NG

```java
abstract class B implements A {
    private void sample() { System.out.println("B"); }
}
```
```
エラー: Bのsample()はAのsample()を実装できません
  (public)より弱いアクセス権限を割り当てようとしました
```
→ 検証済み。

## ケース2：defaultメソッドをprotectedで実装 → NG

```java
abstract class B implements A {
    protected void sample() { System.out.println("B"); }
}
```
```
エラー: Bのsample()はAのsample()を実装できません
  (public)より弱いアクセス権限を割り当てようとしました
```
→ 検証済み。`abstract`クラスであっても関係なくエラーになる。

## ケース3：抽象メソッドをprotectedで実装 → NG

```java
abstract class Employee implements Worker {
    protected void work() { System.out.println("work"); }
}
```
```
エラー: Employeeのwork()はWorkerのwork()を実装できません
  (public)より弱いアクセス権限を割り当てようとしました
```
→ 検証済み。defaultメソッドでも抽象メソッドでも同じルール。

## ケース4：defaultメソッドをpublicで実装 → OK（同じ強さ）

```java
class B implements A {
    public void sample() { System.out.println("B"); }
}
```
→ `B`と表示され成功。検証済み。

## 参考：普通のクラス継承でも同じルール

```java
// 広げる（protected→public）→ OK
class Parent {
    protected void sample() { System.out.println("Parent"); }
}
class Child extends Parent {
    public void sample() { System.out.println("Child"); }
}
```
→ `Child`と表示され成功。検証済み。

```java
// 狭める（public→protected）→ NG
class Parent {
    public void sample() { System.out.println("Parent"); }
}
class Child extends Parent {
    protected void sample() { System.out.println("Child"); }
}
```
```
エラー: Childのsample()はParentのsample()をオーバーライドできません
  (public)より弱いアクセス権限を割り当てようとしました
```
→ 検証済み。

## まとめ

- インターフェースの抽象メソッド・defaultメソッドは、どちらも暗黙的に`public`
- オーバーライド／実装する側は、元のアクセス修飾子より**弱くする（狭める）ことは一律禁止**：`public → protected`も`public → private`も両方アウト
- **広げる**方向（例：`protected → public`）は問題なくOK
- 実装クラスが`abstract`であるかどうかは無関係。「今すぐ全部実装しなくていい」という`abstract`の性質と、「実装するなら弱めてはいけない」というアクセス修飾子のルールは別次元の話
- これはインターフェース実装に限らず、**通常のクラス継承のオーバーライド全般に共通するルール**の一部
