# インスタンスがいくつ作られたか（Stringのインスタンス数を数える問題）

## 検証コード

```java
String a = "sample";
String b = new String("sample");
String c = "sample";
String d = new String("sample");
String e = c;
String f = d;
```

**正解：3つ**（`new`だけを数える「2つ」は誤り）

## `==`で検証

```java
System.out.println("a==c : " + (a == c));   // true
System.out.println("a==b : " + (a == b));   // false
System.out.println("b==d : " + (b == d));   // false
System.out.println("c==e : " + (c == e));   // true
System.out.println("d==f : " + (d == f));   // true
```
→ 検証済み。

## インスタンスが作られたタイミングを数える

| 行 | コード | 新しいインスタンスが作られるか |
|---|---|---|
| `a = "sample";` | リテラル | ✅ **1つ目**（文字列プールに新規作成） |
| `b = new String("sample");` | `new` | ✅ **2つ目**（`new`なので必ず新規） |
| `c = "sample";` | リテラル | ❌（`a`と同じ内容のリテラルなので、プール内の**既存の1つ目を再利用**） |
| `d = new String("sample");` | `new` | ✅ **3つ目**（`new`なので必ず新規） |
| `e = c;` | 参照コピー | ❌（`c`が指しているものをそのまま指すだけ） |
| `f = d;` | 参照コピー | ❌（`d`が指しているものをそのまま指すだけ） |

**合計3つ**（`a`と`c`が共有する1つ＋`b`の1つ＋`d`の1つ）。

## 数える上でのポイント（3種類を区別する）

- **リテラル（`"sample"`）**：最初の1回だけ新規作成され、それ以降の**同じ内容**のリテラルは文字列プールから使い回される（プール機能）
- **`new String(...)`**：中身が同じでも、**毎回必ず新規作成**される（プールを無視する）
- **単なる代入（`e = c`など）**：インスタンスを増やさない。既存の参照をコピーするだけ

「`new`されているものだけを数える」は誤り。**リテラルも「最初の1回」だけは新規にインスタンスが作られる**ということを見落とさないこと。
