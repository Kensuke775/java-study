# 使うことができる引数

## 配列を渡すなら、受け取る側も配列（またはvarargs）でなければならない

```java
public static void main(String[] args) {
    System.out.println(method(args));   // argsはString[]型
}
static int method(String s) { return s.length(); }   // ← ...を外してみる
```
```
エラー: 不適合な型: String[]をStringに変換できません
```

呼び出し側の`args`は`String[]`（配列）。これを受け取るメソッド側は、配列と互換性がある形（`String[]`か、実体が同じ`String...`）でなければ型が合わない。単一の`String`（`...`無し）では受け取れない。

- `method(String... s)` → 実体は`String[]`を受け取るのと同じ → `args`をそのまま渡せる → OK
- `method(String s)` → 単一の`String`しか受け取れない → `String[]`を押し込めない → エラー

問題2でどの選択肢も`String... s`という書き方を採用しているのは、見た目の都合ではなく、**呼び出し元の`args`が配列である以上、受け取る側も配列互換でなければコンパイルが通らない**という必然的な理由による。`static`かどうかとは無関係な、単純な型の代入互換性の話。

## 配列と可変長引数は、同じメソッドの別々の引数として共存できる

```java
public void f(double[] d1, double... d2) {}
```
→ コンパイル成功。

「配列(`T[]`)と可変長引数(`T...`)は同じ扱いだから重複でエラーになる」というルールは、**同じメソッド名で2つの別々のオーバーロードを宣言した時**（例：`f(double[] d)`と`f(double... d)`を別々に定義）に発生するもの。今回のように**1つのメソッドの中の、別々の引数（1番目と2番目）**として`double[]`と`double...`が同居するだけなら、重複でも何でもなく普通に使える。「可変長引数は最後に置かなければならない」というルールさえ守っていればOK。

## `var`は引数の型としてそもそも使えない（可変長かどうかは無関係）

```java
public void c(var x, var... y) {}
```
```
エラー: 'var'はここでは許可されません   ← 2箇所とも
```

`var`を普通の（可変長ではない）引数にしても、やはりエラーになる。

```java
public void c(var x, var y) {}   // 可変長をやめても
```
```
エラー: 'var'はここでは許可されません   ← やっぱり両方エラー
```

つまり「`var`は可変長にできない」のではなく、**`var`はそもそもメソッドの引数の型として使うこと自体が禁止されている**（`var`はローカル変数専用）。「可変長をやめれば直る」という発想は的外れ。

## Arrays.toStringで複数の配列をまとめて出力したい場合

```java
public static void method(double x[], int... y){
    System.out.println(Arrays.toString(x + "" + y));   // ← NG
}
```
```
エラー: toStringに適切なメソッドが見つかりません(String)
メソッド Arrays.toString(double[])は使用できません
  (引数の不一致: Stringをdouble[]に変換できません:)
```

`x + "" + y`は、配列を`+`で連結しようとした時点で、Javaが配列の`toString()`（`[D@1540e19d`のような参照のハッシュ表現）を呼び出して**文字列化**してしまう。結果はもう配列ではなく`String`になっているため、配列専用の`Arrays.toString(...)`には渡せない。

### 正しい書き方：先に`Arrays.toString`で文字列化してから連結する

```java
System.out.println(Arrays.toString(x) + " " + Arrays.toString(y));
// → [1.1, 1.1] [1, 1, 1, 1, 1]
```

「配列を`+`で連結してから`Arrays.toString`に渡す」のではなく、「**先に`Arrays.toString`で文字列化してから`+`で連結する**」という順番が正しい。
