# ローカル変数に定義可能なもの

## ローカル変数とは

**メソッド・コンストラクタ・ブロック（`{}`）の中で宣言される変数**のこと。フィールド（インスタンス変数・クラス変数）と対になる概念で、「インスタンスメソッドの中かどうか」ではなく「クラス直下かメソッド／ブロックの中か」が分かれ目。

- staticメソッドの中の変数もローカル変数
- コンストラクタの中の変数もローカル変数
- メソッドの**引数（パラメータ）**もローカル変数の一種
- `for`/`if`/`try`などのブロックの中の変数もローカル変数

## 使える修飾子はフィールドと全然違う

| | フィールド（クラス直下） | ローカル変数（メソッド・ブロックの中） |
|---|---|---|
| アクセス修飾子（`public`/`private`/`protected`/無指定） | ✅ 使える | ❌ 使えない |
| `static` | ✅ 使える | ❌ 使えない |
| `final` | ✅ 使える | ✅ 使える（ここだけ共通） |
| `transient`/`volatile` | ✅ 使える | ❌ 使えない |
| `var`（型推論） | ❌ 使えない | ✅ 使える（逆にこちらはローカル変数専用） |

**ローカル変数に使える修飾子は実質`final`だけ**。`public`・`static`などクラスメンバー用の修飾子は、ローカル変数には一切使えない。

## 検証問題（問題52）

次のローカル変数の宣言のうち、コンパイルエラーが発生するものはどれですか。（3つ選択）

```java
A. String $_1 = "100";
B. public var x = "1_000_000".length();
C. final var y = Math.random();
D. int var = Integer.parseInt("100");
E. static final Integer INTVALUE = 1_000;
F. char VALUE = (char)100.0F;
G. boolean true = true;
```

→ **正解：B、E、G**

| 選択肢 | 判定 | 理由 |
|---|---|---|
| A | ✅ OK | `$`や`_`を含む識別子は合法（数字始まりでなければOK） |
| **B** | ❌ エラー | ローカル変数に`public`（アクセス修飾子）は不可 |
| C | ✅ OK | `final`＋`var`は組み合わせ可能 |
| D | ✅ OK | `var`は予約"型"名であり完全なキーワードではないため、変数名として使用可能 |
| **E** | ❌ エラー | ローカル変数に`static`は不可 |
| F | ✅ OK | `float`→`char`の明示的キャストは可能（数値系同士は相互にキャスト可、`char`も数値型の一種） |
| **G** | ❌ エラー | `true`は完全な予約語（リテラル）なので識別子に使えない（`var`とは違う） |

**ポイント**：B・Eは「ローカル変数にクラスメンバー用の修飾子は付けられない」という共通ルール、Gは「予約語は識別子に使えない」という別のルール。DとGを比較すると、「`var`は予約"型"名だが識別子として使用可」「`true`/`false`/`null`は完全な予約語で識別子として使用不可」という非対称さが見えてくる。
