# 無名パッケージ（デフォルトパッケージ）

## `package`宣言が無いファイルは、全部「同じ無名パッケージ」に属する

```java
public interface Worker { void work(); }
class Employee implements Worker { ... }   // publicなし
class Engineer extends Employee { ... }    // publicなし
public class Main { ... }
```

どのファイルにも`package`宣言が書かれていない場合、これらは全部**同じ1つの「無名パッケージ（デフォルトパッケージ）」**に属する。`public`が付いていない`Employee`・`Engineer`も、`Main`と**同じパッケージ内**にいることになるので、`Main`から問題なく`new Engineer()`のように使える。

## 「publicが無い＝どこからでも使える」ではない

`public`が付いていないクラスは無指定（package-private）になり、**同じパッケージに属するクラスからしかアクセスできない**。今回`Main`から使えたのは「`public`が無くても大丈夫だったから」ではなく、「たまたま全員が同じ無名パッケージに属していたから」という点が正確。

## 検証：別パッケージ＋publicなし＝importしても使えない

```java
// a/Engineer.java
package a;
class Engineer {}   // publicなし

// b/Main.java
package b;
import a.Engineer;
public class Main {
    public static void main(String[] args) {
        Engineer e = new Engineer();
    }
}
```
```
エラー: aのEngineerはpublicではありません。パッケージ外からはアクセスできません
```
→ 検証済み。`import`を書いていても、`public`が無ければ別パッケージからは使えない。

## まとめ

| 状況 | アクセス可否 |
|---|---|
| 同じ無名パッケージ内（`package`宣言が無いファイル同士） | `public`が無くてもアクセス可能 |
| 別パッケージから、`public`が付いたクラスを`import`して使う | ✅ アクセス可能 |
| 別パッケージから、`public`が無いクラスを`import`しようとする | ❌ `import`を書いてもエラー |

「別パッケージのクラスを使うには`import`が必要」というだけでなく、「**`import`は視界に入れるだけの機能で、そのクラス自体に`public`が付いていることが別途必須**」という2段構えのルールになっている（詳細は[[../import/importはpublicが必要]]参照）。今回のケースはそもそも同じ無名パッケージなので`import`自体が不要、という点も合わせて押さえておく。
