# 連鎖代入（a = b = c = d = 2;）

## 代入`=`は「値を返す式」でもある

```java
int a, b, c, d;
a = b = c = d = 2;
System.out.println(a + " " + b + " " + c + " " + d);   // 2 2 2 2
```
→ 検証済み。全部`2`になる。

## 右から左に評価される

1. `d = 2` → `d`に`2`が代入され、この式自体の値も`2`
2. `c = (d = 2)` → 上の結果（`2`）が`c`に代入され、式の値も`2`
3. `b = (c = ...)` → 同様に`2`が`b`に代入
4. `a = (b = ...)` → 同様に`2`が`a`に代入

結果、全部`2`になる。

## ポイント

「代入は文だけでなく、値を持つ式でもある」という性質を利用した書き方。`if`文の条件式の中に代入を書けたりするのも、同じ「代入は式である」という性質による（例：`if ((x = calc()) > 0)`のような書き方）。
