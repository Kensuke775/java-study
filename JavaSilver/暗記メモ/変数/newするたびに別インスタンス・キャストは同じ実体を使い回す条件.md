# `new`するたびに別インスタンスができる（キャストして同じ実体を使い回したい時の注意）

## 検証コード：newを複数回呼ぶと、そのたびに別インスタンス

```java
((A) new C()).sample();   // 1個目のCインスタンス
((B) new C()).sample();   // 2個目の、全く別のCインスタンス
((C) new C()).sample();   // 3個目の、また別のCインスタンス

C c = new C();             // 4個目の、まっさらな新しいインスタンス
System.out.println(c.value);   // → 0
```
→ `0`と表示される。検証済み。

`new C()`は呼ぶたびに**毎回新しいインスタンスを作る**。最初の3行はそれぞれ「作って、すぐ`sample()`を呼んで、その後どこにも代入せず捨てる」使い捨てのインスタンス（`value`が変化しても、その参照はどこにも残らないので確認できない）。`C c = new C();`はそれらとは無関係な、別のまっさらなインスタンス。

## 同じ実体を使い回したい場合

```java
C c = new C();
((A) c).sample();
((B) c).sample();
((C) c).sample();
System.out.println(c.value);   // → 意図した値になる
```

キャストは実体を変えない（[[静的型が先に決めるルール]]参照）ので、同じ変数`c`を使い回せば、何度キャストしても同じ実体に対して操作していることになる。

## まとめ

- `new`は呼ぶたびに独立した新しいインスタンスを作る。式の中で使い捨てにすると、その後は参照する手段が無い
- 「同じインスタンスに対して複数回操作したい」なら、`new`は1回だけにして、変数を使い回す（キャストしても実体は変わらないので、型を変えて呼び分けることはできる）
