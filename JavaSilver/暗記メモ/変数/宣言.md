# 変数名（識別子）に使える文字

| 種類 | 使えるか |
|---|---|
| 英字（a-z, A-Z） | ✅ |
| 数字（0-9、ただし先頭は不可） | ✅ |
| `_`（アンダースコア） | ✅（先頭でもOK） |
| `$`（ドル記号） | ✅（先頭でもOK） |
| 日本語などUnicode文字（`あ`、`café`のアクセント文字など） | ✅ |
| `-`（ハイフン）、`+`、`!`、`@`など他の記号 | ❌ |

## 検証

```java
int _a = 1;      // OK
int $b = 2;      // OK
int a1 = 3;      // OK（数字は先頭以外ならOK）
int あ = 4;       // OK（日本語も識別子として合法）
int café = 5;    // OK（アクセント付き文字も合法）

int a-b = 1;     // エラー（-は演算子と解釈され、a - b という式に見えてしまう）
```

## ポイント

- 識別子に使える「記号」は実質**`_`と`$`の2つだけ**
- それ以外は英数字か、（日本語含む）Unicodeの「文字」カテゴリに属するものに限られる
- `_`・`$`はどちらも**先頭に置いてもOK**（数字だけは先頭NG）
