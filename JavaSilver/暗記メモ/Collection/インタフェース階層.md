# Collectionのインタフェース階層

## Collectionはクラスではなくインタフェース

`Object`が「すべてのクラスの一番上にある共通の親クラス」なのに対し、`Collection`は「コレクション系インタフェース(`List`・`Set`・`Queue`など)の一番上にある共通の親インタフェース」という位置づけ。役割は似ているが「クラス」と「インタフェース」という別の仕組み。

## 階層図

```
Collection (インタフェース)
   ├── List (インタフェース) extends Collection
   │      └── ArrayList (クラス) implements List
   ├── Set (インタフェース) extends Collection
   └── Queue (インタフェース) extends Collection
```

- `List`の上にあるのは`Collection`だが、これは**スーパークラス**ではなく**スーパーインタフェース**(`List extends Collection`、インタフェース同士の継承)。
- `ArrayList`のようなクラスは`List`を`implements`することで、間接的に`Collection`の機能も持つ。
- `Map`はこの階層に属さない独立した別系統のインタフェース。

## Silverの範囲としての位置づけ

`Collection`・`Iterable`はSilverの直接の出題範囲というよりGold寄り。「`List`/`Set`/`Map`はそれぞれ独立したインタフェースで、`List`と`Set`は`Collection`という共通の親を持つ(`Map`は持たない)」くらいの理解で十分。
