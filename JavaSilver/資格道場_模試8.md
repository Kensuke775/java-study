### 第3問（不正解）

```
 1: class Buffer {
 2:     public void close() { System.out.println("closed"); }
 3: }
 4: public class Main {
 5:     public static void main(String[] args) {
 6:         try (Buffer b = new Buffer()) {
 7:             System.out.println("work");
 8:         }
 9:     }
10: }
```

このプログラムをコンパイルおよび実行した結果として正しいものはどれか。

- A. 行6 の記述が原因でコンパイルエラーになり、実行できない
- B. work と表示された後、closed と表示される
- C. work と表示されるが、closed は表示されない
- D. コンパイルは通るが、実行時に例外がスローされて work は表示されない

<br>
<br>
<br>
<br>
<br>

**正解: A**

try-with-resources に書けるのは**`AutoCloseable`（または`Closeable`）を実装した型**だけ。`close()`という名前のメソッドを持っているだけでは足りず、`implements AutoCloseable`が無いので行6 でコンパイルエラー。


このプログラムを実行したときの**標準出力**として正しいものはどれか。

### 第18問（不正解）

```
 1: class Engine {
 2:     int power = 90;
 3: }
 4: class Wheel {
 5:     int size = 17;
 6: }
 7: public class Garage {
 8:     public static void main(String[] args) {

13:             System.out.println(e.power);
```

このプログラムをコンパイル・実行しようとしたときの結果はどれか。

- A. 17

<br>
<br>
<br>
<br>
<br>

### 第58問（不正解）

```
 1: public class Loader {
 2:     static void load(int n) {
 3:         try {
 4:             System.out.print("s");
 5:             if (n == 0) {
 6:                 throw new IllegalStateException("x");

11:         } finally {

14:         System.out.print("w");
```

このプログラムを実行した結果として正しいものはどれか。

このコードをコンパイルすると、どうなるか。

### 第4問

```
 1: import java.util.ArrayList;
 2: 
 3: public class Slots {
 4:     public static void main(String[] args) {
 5:         ArrayList<Integer> slots = new ArrayList<>();
 6:         slots.add(10);
 7:         slots.add(20);
 8:         slots.add(1);
 9:         slots.remove(1);
10:         System.out.println(slots);
11:     }
12: }
```

このプログラムを実行したときに出力される内容はどれか。

- A. 行10 で [10, 20] と出力される
- B. 行10 で [10, 1] と出力される
- C. 行10 で [20, 1] と出力される
- D. 行9 で IndexOutOfBoundsException がスローされる

<br>
<br>
<br>
<br>
<br>

**正解: B**

`remove(1)`の`1`は`int`リテラルなので、変換なしで一致する`remove(int index)`が選ばれる（ボクシングが検討されるのは、変換なしの候補が無いときだけ）。消えるのは添字1の`20`。値の`1`を消すなら`remove(Integer.valueOf(1))`。`indexOf`は`indexOf(Object)`しか無いので`int`を渡すとボクシングされる、という違いも合わせて押さえる。
