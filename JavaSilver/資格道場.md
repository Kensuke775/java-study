# 資格道場

資格道場（Java Silver SE 17 / 1Z0-825 の無料50問）で、難しいと感じた問題をまとめたもの。

---

### 問1

```
 1: class Tag {
 2:     String label;
 3:     Tag next;
 4:     int size() { return label.length(); }
 5: }
 6: public class TagDemo {
 7:     public static void main(String[] args) {
 8:         Tag t = new Tag();
 9:         t.label = "alpha";
10:         System.out.println(t.size());
11:         System.out.println(t.next.size());
12:         System.out.println("end");
13:     }
14: }
```

このプログラムを実行したときの結果はどれか。

- A. 「5」が出力された後、行11 で `NullPointerException` がスローされる
- B. 「5」と「5」が出力された後、行12 で「end」が出力される
- C. 「5」が出力された後、行4 で `label` が `null` のため `NullPointerException` がスローされる
- D. 「5」と「0」が出力された後、行12 で「end」が出力される

<br>
<br>
<br>
<br>
<br>

**正解: A**（回答: A・正解）

行8 でインスタンスは作られるが、参照型のフィールドは既定値の`null`になる。行9 で値が入るのは`label`だけで、`next`は`null`のまま。行10 は`label`が`"alpha"`なので`5`。行11 は`null`の`next`に対して`size()`を呼ぼうとするため、**呼び出した行11 の時点で**`NullPointerException`になり、行12 には到達しない。`size()`の中身（行4）は実行すらされないので、C は誤り。`null`への呼び出しが`0`や空の値を返すこともない（D は誤り）。

### 問2

```
 1: import java.util.Arrays;
 2: 
 3: public class Match {
 4:     public static void main(String[] args) {
 5:         int[] left = new int[3];
 6:         int[] right = new int[3];
 7:         Arrays.fill(left, 2);
 8:         right[0] = 2;
 9:         right[1] = 2;
10:         right[2] = 2;
11:         System.out.println(Arrays.equals(left, right) + "," + (left == right));
12:     }
13: }
```

このプログラムを実行したときの出力はどれか。

- A. `true,false`
- B. `true,true`
- C. `false,false`
- D. 行11 でコンパイルエラーになる

<br>
<br>
<br>
<br>
<br>

**正解: A**（回答: C）

`Arrays.fill(left, 2)`は全要素を`2`で埋めるので`left`は`{2, 2, 2}`、`right`も`{2, 2, 2}`。`Arrays.equals`は**中身を要素ごとに**比べるので`true`。`left == right`は**同じ配列オブジェクトか**を比べ、行5・行6で別々に生成しているので`false`。配列の`left.equals(right)`は`Object`の`equals`のままなので参照比較になり`false`。中身を比べたいときは必ず`Arrays.equals`を使う。

| 書き方 | 比べるもの | 結果 |
|---|---|---|
| `Arrays.equals(left, right)` | 中身 | `true` |
| `left == right` | 参照 | `false` |
| `left.equals(right)` | 参照（`Object`のまま） | `false` |

### 問3

```
 1: import java.util.ArrayList;
 2: 
 3: public class ScoreBoard {
 4:     public static void main(String[] args) {
 5:         ArrayList<Integer> scores = new ArrayList<>();
 6:         scores.add(40);
 7:         scores.add(50);
 8:         scores.add(40);
 9:         scores.set(2, 60);
10:         System.out.println(scores.indexOf(40) + "," + scores.indexOf(50) + "," + scores.indexOf(70) + "," + scores.size());
11:     }
12: }
```

このプログラムを実行したときに出力される内容はどれか。

- A. `1,2,0,3`
- B. `0,1,-1,3`
- C. `0,1,0,3`
- D. `1,2,-1,4`

<br>
<br>
<br>
<br>
<br>

**正解: B**（回答: B・正解）

行9 の`set(2, 60)`は置き換えなのでリストは`[40, 50, 60]`、要素数は3のまま。`indexOf`は**値を渡して、最初に一致した添字を返す**（0始まり、見つからなければ`-1`）。添字を渡して値を取るのは`get`のほう。`indexOf`は`indexOf(Object)`しかないので`40`は`Integer`にボクシングされて普通に動くが、`remove`は`remove(int index)`と`remove(Object)`があるため、`List<Integer>`で`remove(40)`と書くと添字40の削除になり`IndexOutOfBoundsException`になる点と区別する。

| メソッド | 渡すもの | 返すもの |
|---|---|---|
| `get(int index)` | 添字 | 値 |
| `indexOf(Object o)` | 値 | 添字（なければ`-1`） |

### 問4

```
 1: public class Basket {
 2:     static void pack(StringBuilder sb) {
 3:         sb.append("-egg");
 4:         sb = new StringBuilder("cake");
 5:         sb.append("-jam");
 6:     }
 7:     public static void main(String[] args) {
 8:         StringBuilder box = new StringBuilder("milk");
 9:         pack(box);
10:         System.out.println(box);
11:     }
12: }
```

このプログラムを実行したときの結果はどれか。

- A. `milk` と表示される
- B. `milk-egg` と表示される
- C. `milk-egg-jam` と表示される
- D. `cake-jam` と表示される

<br>
<br>
<br>
<br>
<br>

**正解: B**（回答: B・正解）

Javaは参照を値渡しする。`sb.append("-egg")`は`box`と同じオブジェクトを操作するので`box`も`milk-egg`になる。その後`sb = new StringBuilder("cake")`はローカル変数`sb`の指す先を切り替えるだけで`box`には影響しない。`sb.append("-jam")`は新しいオブジェクトへの操作なので`box`は関係ない。結果`box`は`milk-egg`のまま。

### 問5

```
 1: import java.util.ArrayList;
 2:
 3: public class Clean {
 4:     public static void main(String[] args) {
 5:         ArrayList<String> list = new ArrayList<>();
 6:         list.add("a");
 7:         list.add("");
 8:         list.add("");
 9:         list.add("b");
10:         for (int i = 0; i < list.size(); i++) {
11:             if (list.get(i).isEmpty()) list.remove(i);
12:         }
13:         System.out.println(list);
14:     }
15: }
```

このプログラムを実行したときの結果はどれか。

- A. `[a, b]` と表示される
- B. `[a, , b]` と表示される
- C. `ConcurrentModificationException` がスローされる
- D. `[a, b]` と表示されるが、1つ空文字列が残る

<br>
<br>
<br>
<br>
<br>

**正解: D**（回答: D・正解）

前から削除すると削除後に後ろの要素が前にずれる。`i=1`で最初の`""`を削除すると2つ目の`""`が`index=1`に移動し、次のループで`i=2`に進むためスキップされる。取り残しが発生して`[a, "", b]`になる。空文字列を正しく全削除するには後ろから削除するか`removeIf`を使う。拡張forで`remove`すると`ConcurrentModificationException`になる。

| 方法 | 結果 |
|---|---|
| 前から `remove(i)` | 取り残しあり |
| 後ろから `remove(i)` | 正常 |
| 拡張for + `remove` | `ConcurrentModificationException` |
| `removeIf` | 正常（実務推奨） |

### 問6

```
 1: class Employee {
 2:     String role = "employee";
 3: }
 4: class Manager extends Employee {
 5:     String role = "manager";
 6: }
 7: public class Main {
 8:     public static void main(String[] args) {
 9:         Manager m = new Manager();
10:         Employee e = m;
11:         System.out.println(e.role);
12:         System.out.println(m.role);
13:     }
14: }
```

このプログラムを実行したときの結果はどれか。

- A. `manager` / `manager`
- B. `employee` / `employee`
- C. 行11 でコンパイルエラーになる
- D. `employee` / `manager`

<br>
<br>
<br>
<br>
<br>

**正解: D**（回答: D・正解）

フィールドはメソッドと異なり動的ディスパッチが適用されない。参照型（コンパイル時の型）で決まる。`e`の参照型は`Employee`なので`Employee`の`role`が参照され`"employee"`、`m`の参照型は`Manager`なので`Manager`の`role`が参照され`"manager"`になる。メソッドならオーバーライドで実体の型が使われるが、フィールドは隠蔽（hiding）なので参照型が優先される。
