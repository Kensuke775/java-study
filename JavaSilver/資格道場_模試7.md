### 第4問（不正解）

```
 1: class SyncException extends Exception {
 2:     SyncException(String message, Throwable cause) {
 3:         super(message);
 4:     }
 5: }
 6: public class Sync {
 7:     public static void main(String[] args) {
 8:         try {
 9:             try {
10:                 throw new IllegalArgumentException("abc");
11:             } catch (IllegalArgumentException e) {
12:                 throw new SyncException("wrap", e);
13:             }
14:         } catch (SyncException e) {
15:             System.out.println(e.getMessage() + "/" + e.getCause());
16:         }
17:     }
18: }
```

このプログラムを実行したときの出力はどれか。

- A. wrap/abc という1行が画面に表示される
- B. wrap/java.lang.IllegalArgumentException: abc
- C. null/java.lang.IllegalArgumentException: abc
- D. wrap/null という1行が画面に表示される

<br>
<br>
<br>
<br>
<br>

**正解: D**

行2 で`cause`を受け取っていても、行3 で`super(message)`しか呼んでいないので原因は保持されず、`getCause()`は`null`。原因を残すには`super(message, cause)`と第2引数で親に渡す必要がある。**引数で受け取ることと、親に渡して連鎖を作ることは別。**

このプログラムを JDK 17 でコンパイル・実行した結果はどれか。

- C. 行2 でコンパイルエラーになり、何も表示されない

```

 5: }
 6:
 7: // p2/Leaf.java

10: public class Leaf extends Node {
```

Leaf クラスを実行した結果はどれか。

- A. 行16 で root と表示される。
- B. 行16 で leaf と表示される。

### 第22問（不正解）

```
 1: class AuditException extends Exception {
 2:     AuditException(String m) { super(m); }
 3:     int code() { return 7; }
 4: }
 5: class TraceException extends Exception {
 6:     TraceException(String m) { super(m); }
 7: }
 8: public class Journal {
 9:     static void write(int n) throws AuditException, TraceException {
10:         if (n == 0) {
11:             throw new TraceException("no id");
12:         }
13:         throw new AuditException("locked");
14:     }
15:     public static void main(String[] args) {
16:         try {
17:             write(1);
18:         } catch (AuditException | TraceException e) {
19:             System.out.println(e.getMessage() + e.code());
20:         }
21:     }
22: }
```

このプログラムについて正しく述べているものはどれか。

- A. 行19 でコンパイルエラーになる。e の型では code() を呼び出せない
- B. 実行すると locked7 と表示される
- C. 行18 でコンパイルエラーになる。異なる階層の型を | で並べている
- D. 実行すると locked と表示され、行3 の値は出力されない

<br>
<br>
<br>
<br>
<br>

**正解: A**

multi-catch の変数`e`の型は、並べた型の**共通の親**（ここでは`Exception`）として扱われる。`AuditException`にしかない`code()`は呼べずコンパイルエラー。`getMessage()`のように共通の親が持つメソッドなら呼べる。片方固有のメソッドを使いたいなら`catch`を型ごとに分ける。

### 第3問

```
 1: public class Sensor {
 2:     public static void main(String[] args) {
 3:         int reading = 200;
```

<br>

### 第21問（2つ選択）

```

 2:     public static void main(String[] args) {
 3:         String s = """
 4:                 aa
 5:                   bb
```

- A. 行3 では開き """ の直後で改行しているため、テキスト・ブロックの宣言として形が不正でありコンパイルエラーになる

### 第25問（2つ選択）

```
 1: class Device {
 2:     static String kind() { return "Device"; }
 3:     String label() { return "device"; }
 4: }
 5:
 6: class Printer extends Device {
 7:     static String kind() { return "Printer"; }
 8:     String label() { return "printer"; }
 9:     String eject() { return "eject"; }
10: }
11:
12: public class Office {
13:     public static void main(String[] args) {
14:         Device d = new Printer();
15:         System.out.println(d.kind() + "/" + d.label());
16:         Object o = d;
17:         String s = ((Printer) o).eject();
18:         System.out.println(s);
19:     }
20: }
```

- A. 行15 は Printer/printer を出力する。行14 で作られた実体が Printer なので、二つの呼び出しはどちらも Printer 側のものに解決される
- B. 行17 を ((Device) o).eject() と書き換えても、実体が Printer である以上 eject を呼び出せる
- C. 行15 は Device/printer を出力する。static の付いたメソッドは変数に書かれた型で選ばれ、付いていないメソッドは実体で選ばれる
- D. 行14 の d に対して d.eject() と書くと、実体が Printer であってもコンパイルできない

<br>
<br>
<br>
<br>
<br>

**正解: C、D**

`static`メソッドは**変数の宣言型**、インスタンスメソッドは**実体**で選ばれる → `Device/printer`。呼べるかどうかは宣言型で判定されるので`d.eject()`はエラー。`Object`→`Printer`のダウンキャストはコンパイルを通り、実行時にチェックされる。
