## 問題1：トップレベルクラスの宣言に使える修飾子

次の修飾子のうち、トップレベルクラス（`class`）の宣言に**使えないもの**を全て選んでください。

`public` / `final` / `abstract` / `sealed` / `private` / `protected` / `static` / `non-sealed`

<details>
<summary>解答・解説</summary>

**使えない：`private`・`protected`・`static`**（3つ）

- `private`・`protected`：トップレベルの型自体には使えない（package-privateかpublicのみ。ネストしたクラスなら使える点に注意）
- `static`：トップレベルクラス自体には使えない（ネストしたクラスになら使える）
- `sealed`／`non-sealed`：使える（ただし`permits`で許可リストを書く必要がある。`non-sealed`は継承元がsealedの場合のみ意味を持つ）
- `abstract`・`final`：どちらも単体では使える。ただし**`abstract`と`final`を同時に付けると矛盾でエラー**（インスタンス化禁止と継承禁止が両立しないため）

**検証済みエラー文言**：
- `private class`：`修飾子privateをここで使用することはできません`
- `protected class`：`修飾子protectedをここで使用することはできません`
- `static class`：`修飾子staticをここで使用することはできません`
- `abstract final class`：`修飾子abstractとfinalの組合せは不正です`

</details>

## 問題2：インターフェースの宣言に使える修飾子

次の修飾子のうち、`interface`の宣言に**使えないもの**を全て選んでください。

`public` / `abstract` / `final` / `sealed` / `non-sealed` / `private`

<details>
<summary>解答・解説</summary>

**使えない：`final`・`private`**（2つ）

- `final`：インターフェースは「実装される（継承される）」ことが前提の型なので、継承を禁止する`final`とは根本的に矛盾する→エラー
- `private`：トップレベルでは使えない（ネストしたインターフェースなら別）
- `abstract`：書いても冗長なだけでエラーにはならない（インターフェースは元々暗黙で`abstract`）
- `sealed`・`non-sealed`：クラスと同じく使える（`permits`必須）

**検証済みエラー文言**：
- `public final interface`：`修飾子interfaceとfinalの組合せは不正です`
- `public abstract interface`：エラーなし（冗長なだけ）

</details>

## 問題3：recordの宣言に使える修飾子

次の修飾子のうち、`record`の宣言に**使えないもの**を全て選んでください。

`public` / `final` / `abstract` / `sealed` / `non-sealed` / `private`

<details>
<summary>解答・解説</summary>

**使えない：`abstract`・`sealed`・`non-sealed`**（3つ）

- `record`は常に暗黙で`final`（継承不可）。そのため：
  - `abstract`（インスタンス化を前提にしない）とは矛盾 → エラー
  - `sealed`／`non-sealed`（継承階層を作るための修飾子）も、そもそも継承できないrecordには無意味かつ構文エラー
- `final`：書いても冗長なだけでエラーにはならない（recordは元々暗黙でfinal）
- `private`：トップレベルでは使えない（これはrecord特有の話ではなく、どの型宣言にも共通）

**検証済みエラー文言**：
- `public abstract record`：`修飾子abstractをここで使用することはできません`
- `sealed record ... permits ...`：`class, interface, enumまたはrecordがありません`（構文エラー扱い）

</details>

## 問題4：メソッドの修飾子の組み合わせ

次の組み合わせのうち、**エラーになるもの**を全て選んでください（すべて抽象クラスの中のメソッドとする）。

A. `public abstract void m();`
B. `protected abstract void m();`
C. `private abstract void m();`
D. `static abstract void m();`
E. `final abstract void m();`

<details>
<summary>解答・解説</summary>

**エラーになる：C・D・E**

- `abstract`メソッドは「サブクラスでオーバーライドされること」が前提
- `private`：オーバーライド自体ができない（外から見えないので）→ 矛盾
- `static`：オーバーライドの対象外（動的束縛が効かない）→ 矛盾
- `final`：オーバーライド禁止という意味 → `abstract`（オーバーライド必須）と正反対で矛盾

`public`・`protected`はオーバーライド可能なアクセス修飾子なので、`abstract`と組み合わせても問題ない。

**共通する覚え方**：**「`abstract`は必ずオーバーライドされる」という前提と矛盾する修飾子（`private`・`static`・`final`）は、`abstract`と共存できない。**

</details>
