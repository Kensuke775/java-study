## 問題2-6

次のプログラムで、コンパイルエラーになる箇所は(1)から(9)のどれか。（3つ選択）

```java
 1  public class Main {
 2      public static void main(String[] args) {
 3          B b = new C();
 4          A t = new C();
 5
 6          b.test(1);            // (1)
 7          (A)b.test(2);          // (2)
 8          ((A)b).test(3);        // (3)
 9          t.test(4);             // (4)
10          (A)t.test(5);          // (5)
11          ((A)t).test(6);        // (6)
12      }
13  }
14
15  sealed interface A permits C {   // (7)
16      void test(int i);
17  }
18
19  class B {                        // (8)
20      public static final int NUM = 2;
21  }
22
23  final class C extends B implements A {   // (9)
24
25      @Override
26      public void test(int i) {
27          System.out.println(i * B.NUM);
28      }
29
30  }
```

A. (1)
B. (2)
C. (3)
D. (4)
E. (5)
F. (6)
G. (7)
H. (8)

**実施記録**

回答：
正解：A, B, E （(1)(2)(5)）
迷ったポイント：
- (1) b.test(1) → B型にはtestメソッドが存在しない（Bはフィールドnumしか持たない）
- (2) (A)b.test(2) → カッコが無いため (A)(b.test(2)) と解釈され、戻り値へのキャストになる。しかもb.test(2)自体がB型にtestが無くエラー。さらにキャスト式単体は文として書けない。
- (3) ((A)b).test(3) → 先にbをAへキャストしてからtestを呼んでいるので正常
- (5) (A)t.test(5) → カッコが無いため (A)(t.test(5)) と解釈され、戻り値（void）へのキャストになる。キャスト式単体は文として書けないため常にエラー（voidかどうかは無関係）
- (6) ((A)t).test(6) → 先にtをAへキャストしてからtestを呼んでいるので正常
- (A)X.method() の形は常に (A)(X.method()) と解釈される（メソッド呼び出しの方がキャストより強く結びつく）。Xを先にキャストしたいなら ((A)X).method() と明示的にカッコで囲む必要がある。
