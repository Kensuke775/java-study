## 問題2-3

次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。（1つ選択）

```java
public class Value {
    private String contents;

    public Value(String contents) {
        super();
        this.contents = contents;
    }
    public Value() {
        this.contents = "";
    }
    public static void print() {
        System.out.println(contents);
    }
}
```

```java
public class Main {
    public static void main(String[] args) {
        Value.print();
    }
}
```

A. 何も表示されない
B. ""が表示される
C. コンパイルエラーが発生する
D. 実行時に例外がスローされる

**実施記録**

回答：
正解：C
迷ったポイント：staticメソッドprint()の中で、staticではないインスタンス変数contentsに直接アクセスしている。エラー「staticでない変数 contentsをstaticコンテキストから参照することはできません」。
