## 問題28

次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。（1つ選択）

```java
 1  public class Sample {
 2      public static void main(String[] args) {
 3
 4          Item a = new Item("A");
 5          System.out.print(a.name + a.id + ",");
 6          Item b = new Item("B");
 7          System.out.print(b.name + b.id + ",");
 8          b.id = "2";
 9          a.name = "C";
10          System.out.print(a.name + a.id + ",");
11          System.out.print(b.name + b.id + ",");
12
13      }
14  }

16  class Item {
17      public static String id;
18      public String name;
19      public Item(String name) {
20          this.name = name;

22      }
23  }
```

A. A1,B1,C1,B2,
B. A1,B1,C2,B2,
C. A1,B2,C2,B2,
D. C1,B2,C1,B2,
E. C1,B1,C1,B2,

**実施記録**

回答：
正解：B
迷ったポイント：staticフィールドは全インスタンス共有。b.id="2"の変更がa.idにも反映される点、コンストラクタ内のid="1"は「newのたびに自動で戻る」わけではなく明示的な代入が毎回実行されているだけという点。
