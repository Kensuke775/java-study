### 問1

```java
 1: import java.io.IOException;
 2: class Loader {
 3:     String kind() {
 4:         return "base";
 5:     }
 6:     void load() {
 7:         System.out.println(kind());
 8:     }
 9: }
10: class FileLoader extends Loader {
11:     String kind() {
12:         return "file";
13:     }
14:     void load() throws IOException {
15:         System.out.println(kind());
16:     }
17: }
18: public class Main {
19:     public static void main(String[] args) {
20:         Loader l = new FileLoader();
21:         l.load();
22:     }
23: }
```

このプログラムをコンパイルして実行したときの結果はどれか。

- A. `base` と表示される
- B. `file` と表示される
- C. 行14 でコンパイルエラーになる
- D. 行21 でコンパイルエラーになる

<br><br><br><br><br>

**正解: D**

行14の `load()` は親の `void load()` をオーバーライドしようとしているが、`throws IOException` を追加している。オーバーライドで `throws` を広げることはNG（親が宣言していないチェック例外は追加できない）。これはコンパイルエラーになる。

さらに行21では `Loader` 型の参照 `l` から `load()` を呼んでいるが、`Loader.load()` は `throws` 宣言がないのでチェック例外を宣言しているメソッドは呼び出し側から見えない。

| 状況 | ルール |
|---|---|
| オーバーライドの `throws` | 親より広げてはNG |
| 参照型でのメソッド呼び出し | コンパイル時は参照型のシグネチャで判定 |

### インポート優先順位とFQNアクセスのまとめ

同じ単純名のクラスが複数パッケージにある場合のアクセス方法：

```java
import draft.*;
import press.*;
import press.Note;  // 単一型インポートが優先される

public class Main {
    public static void main(String[] args) {
        Note n = new Note();           // press.Note（単一型インポートが勝つ）
        System.out.println(n.level);   // 2

        System.out.println(new draft.Note());  // FQNで別パッケージのクラスを使う
        press.Note pN = new press.Note();      // FQNで型宣言もできる
    }
}
```

| 書き方 | 解決されるクラス |
|---|---|
| `Note n` | `press.Note`（単一型インポート優先） |
| `new draft.Note()` | `draft.Note`（FQNで直接指定） |
| `press.Note pN` | `press.Note`（FQNで型宣言） |

- FQNでのインスタンス生成: `new パッケージ名.クラス名()`
- `draft.Note.new Note()` はNG（無効な文法）

### 問2

```
 1: public class Letters {
 2:     public static void main(String[] args) {
 3:         String word = "code";
 4:         int n = 0;
 5:         for (char c : word) {
 6:             n++;
 7:         }
 8:         System.out.println(n);
 9:     }
10: }
```

このプログラムをコンパイルして実行したときの結果として正しいものはどれですか。

- A. 行5 でコンパイルエラーになる
- B. 4 と出力される
- C. 0 と出力される
- D. 実行時に例外がスローされる

<br>
<br>
<br>
<br>
<br>

**正解: A**（回答: 不正解）

拡張forのコロンの右側に書けるのは**配列**か**`Iterable`を実装した型**（`List`など）だけ。`String`はどちらでもないので行5でコンパイルエラー（「for-eachは式のタイプに使用できません」）。JavaScriptの`for...of`は文字列を回せるが、Javaでは回せない。1文字ずつ扱いたいときは次のどちらか。

```java
for (char c : word.toCharArray()) { }          // 配列に変換して拡張for
for (int i = 0; i < word.length(); i++) {      // 配列にせず、普通のforとcharAt
    char c = word.charAt(i);
}
```
